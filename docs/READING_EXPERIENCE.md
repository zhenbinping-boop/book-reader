# 阅读经验与读书功名

2026-11-18 更新。通过有效阅读时间积累经验，使用八个科举主题段位。书架的「我的书斋」显示当前功名，可在功名印谱查看经验、晋升门槛和达成日期。「设置 → 读书功名」显示今日额度和完整规则。正文顶栏显示计时状态，随阅读工具栏一起隐藏。读书直接进入正文，独立打坐有自己的行迹。

## 数值与节奏

|---|---:|---:|---:|
| 童生 | 0 | 0 小时 | — |
| 秀才 | 600 | 10 小时 | 10 小时 |
| 举人 | 3,000 | 50 小时 | 40 小时 |
| 贡士 | 9,000 | 150 小时 | 100 小时 |
| 进士 | 24,000 | 400 小时 | 250 小时 |
| 探花 | 48,000 | 800 小时 | 400 小时 |
| 榜眼 | 84,000 | 1,400 小时 | 600 小时 |
| 状元 | 132,000 | 2,200 小时 | 800 小时 |

每分钟 1 点，无连签、倍率、翻页量或完成一本书的额外奖励；不因中断一天而扣除经验。各段所需增量逐渐变大。第一段位需要约 20 次半小时有效阅读，后期强调长期积累。每日最多计入 3 小时，因此即使每天满额，状元也至少需要 734 个自然日；按每日 1 小时约为 6 年。这是按用户「时间要求严苛一点」制定的产品门槛，不是经用户研究证明的最佳平衡点。

## 有效计时

- 正文完成加载、窗口获得焦点、网页可见、原生 App 位于前台时才累计。TXT、PDF、EPUB 共用同一机制，不用打坐计时换算阅读经验。
- 每次打开书籍建立一条阅读会话；有效时间累计满 5 分钟后，计入该次全部时间。退出或刷新前不足 5 分钟的会话不计经验，也不会与其他短会话拼接。页面内临时暂停后继续同一次会话。
- 打开目录 / 书签 / 笔记面板、回读窗、外观 / 显示设置或划词操作浮层时暂停。
- 最近 3 分钟没有真实滚动、按键或触控时暂停。鼠标移动、合成 click、重复按键不刷新活跃窗口。继续操作正文即可恢复；自动滚动产生的浏览器原生 scroll 事件也可能被视为活动，不能据此证明用户确实阅读。
- 每秒读取单调时钟，逐段累计。超过 5 秒的调度间隔或明显系统时钟跳变不补算，之后需要一次阅读操作恢复。页面隐藏、原生后台、返回与卸载时尝试立即落库，平时每 5 秒保存；系统强杀仍可能损失最后几秒。
- 同设备 IndexedDB 事务维护唯一计时租约。其他窗口等待，旧租约失效后丢弃未确认时段；跨设备不共享实时租约。
- 先按本地自然日汇总达标会话，再对当日时间应用 3 小时上限。跨午夜的采样精确拆日；剩余不足一分钟跨会话 / 跨日保留。超上限的有效时间可统计，但不转换为经验。

本地应用无法确认视线、理解程度，也不提供可信的防篡改服务。上述规则用于限制普通挂机和重复结算；手工修改本地数据库、设备日期或在不同设备同时操作不在可靠防护范围内。旧进度和打坐历史不能证明此前实际阅读时长，因此上线前不追补经验。

## 数据、备份与实现

Dexie v6 新增 `readingSessions` 与 `readingState`，继承原书籍、进度、笔记与打坐数据。会话保存唯一 ID、书名 / 文件指纹快照、起止检查点、累计有效毫秒及每天明细；删除一本书不会撤销已获得的阅读经验。

经验和段位始终从有效时长推导，不保存可独立相加的 XP 余额。备份 schemaVersion 仍为 1，新增可选 `readingSessions`；旧备份可继续恢复。累计检查点按同一会话 ID 取不倒退的较大版本，不做相加。损坏记录在写库前拒绝，另一设备的实时租约不参与备份。恢复多个不同设备的记录后仍按日执行统一上限。

- `src/lib/readingExperience.js`：规则、日界线、纯时钟、记录校验 / 合并、经验与段位。
- `src/lib/readingStore.js`：事务计时租约与累计检查点。
- `src/hooks/useReadingTracker.js`：三格式正文、生命周期、真实活动和保存重试接入。
- `src/components/ReadingGrowth.jsx`、`src/reading-growth.css`：功名摘要、段位表、规则与顶栏状态。
- `tests/readingExperience.test.mjs`：已知时长、阈值、每日上限、午夜、暂停、冻结 / 改时钟、去重与各段位边界。
- `dev-reading-xp.html`：v5 升级、三格式真实计时、失焦 / 面板暂停、多窗口锁冲突 / 失效、已知 10 小时对照、备份去重 / 回退 / 损坏与打坐独立性。

复用现有阅读就绪状态、生命周期与原生 App 事件、Dexie liveQuery、备份事务、InkDialog 和浏览器验收工具；项目此前只有位置检查点和可后台运行的打坐时钟，二者均不能作为有效阅读计时，因此新增独立计时模块。Android / iOS 真机的锁屏生命周期、帧率和系统强杀仍需设备验收。
