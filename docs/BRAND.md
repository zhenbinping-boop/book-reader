# 栖读：名称、图标与移动端适配

更新于 2026-10-26。名称取意「一卷在手，心有所栖」。

## 当前图案与来源

用户要求生成软件图标，并否定了第一版通用立体书本方案。当前版本采用朱砂藏书印：线装书的封面与书房屋檐融为一个图案，暖宣纸为底。没有把中文名称烧进桌面位图，应用名称由系统显示，界面文字印由 HTML 排版。

生成工具为内置 `imagegen`，不是外部下载素材。原始生成图为 `assets/brand/qidu-seal-generated.png`，随后通过同一工具提取的透明印章为 `assets/brand/qidu-seal-cutout.png`。当前工具未提供可指定或核验具体模型版本的参数。

完整生成及透明提取提示见 [PROMPTS.md](../assets/brand/PROMPTS.md)。图标输出以透明印章为唯一制作源；保留生成图用于追溯。

## 重新生成

```sh
npm ci
npm run icons
```

`tools/make_icons.mjs` 使用开发依赖 `sharp` 缩放、合成和分离单色层，不调用付费生成服务。旧命令 `python tools/make_icons.py` 转交同一生成器，不会把旧通用图标重新写回。

产物提交入库，常规网页或原生构建使用已提交图标，不需要重复生成美术。`assets/brand/` 不在公开网页目录内。

## 规格与裁切

| 使用处 | 规格与规则 |
| --- | --- |
| 普通 PWA 图标 | 192 / 512px；印章约占画布宽度 62% |
| PWA maskable | 独立 512px 图标，印章占宽约 54%，方形四角位于中心直径 80% 安全圆内 |
| Apple touch | 180px RGB，独立文件 |
| 浏览器小图标 | 32px，占宽约 72%，适当放大主体 |
| iOS AppIcon | 1024px RGB、无 alpha、无预制圆角 |
| 安卓传统图标 | mdpi 到 xxxhdpi，48 / 72 / 96 / 144 / 192px，另有圆形图标 |
| 安卓自适应前景 | 108dp，印章约占宽 42%；计入方形四角后仍位于直径 66dp 的安全圆内 |
| 安卓主题图标 | Android 13+ 独立单色层；朱砂部分为实体，阴刻纹样为空，颜色交给系统 |
| iOS 启动画面 | 128pt 图像框，1x / 2x / 3x 透明资源；约束居中，独立真实文字名称，支持明暗底色 |

生成器检查透明源格式，并逐像素检查安卓自适应前景未超出安全圆。系统应用圆角或圆形遮罩，原画不预画圆角。

## 更新与验证边界

软件版本递增到 `0.3.0-alpha.2` / `30002`；显示名称更改为栖读，Android 应用 ID、iOS bundle identifier、数据库名及备份识别字段不变。保留原固定签名约定。

浏览器布局检查覆盖 320 / 390 / 430 / 768 / 1280px 与浅色 / 深色，检查印章中每个字的包围框、页面横向溢出和运行时异常。原有 `dev-ink.html` 覆盖藏书、笔记和备份流程。

本地网页检查和 Capacitor 资源同步不等于 Android APK 或 Xcode 编译通过；手机桌面的实际名称和图标需要安装更新后的原生包才会改变。iOS 启动画面的约束仍需由 Xcode 和实际设备最终验证。
