# 阅读器 v0.2.0-alpha.2 · 古风书房

本次 Android 安装包内置新版界面及全部离线资源。

- 宣纸、水墨山景、朱砂印章与四款线装书封；手机底部导航、桌面侧栏。
- 书架继续阅读、搜索、在读 / 待读 / 已读筛选，编辑书名、作者、分组及书封。
- 摘录支持个人感想、标签；全局笔记中心搜索、筛选、返回原文与 Markdown 导出。
- PDF / TXT / EPUB 统一阅读工具栏；保留已修复的续读、手势及选词笔记功能。
- 新增本地宋体与轻量动效，支持减少动态效果；山景、书封与字体均内置安装包。

## 安装与更新

- Android 10+，Android System WebView 140+。
- 下载 `book-reader-v0.2.0-alpha.2.apk`，安装后显示为「阅读器·古风版」。新应用 ID 为 `io.github.zhenbinpingboop.bookreader.ink`，可与旧版「阅读器」共存，不覆盖旧应用及其数据。
- 旧版签名密钥未能找回，本次使用已固定的新签名。后续古风版保持相同应用 ID 和签名，递增版本号以便覆盖更新。

### 迁移书籍与笔记

1. 在旧版「阅读器」打开「备份与恢复」，勾选包含原文件后导出 `.json` 备份（旧版可能标为「连 PDF 原文件一起导出」）。
2. 在新版「阅读器·古风版」进入「设置 → 导出备份 / 恢复备份」，选择备份文件，确认恢复。
3. 核对书籍、进度、书签及笔记。未包含原文件时，重新导入同一书籍文件即可接回记录。确认迁移完整前保留旧应用。

两个应用及浏览器版的书库独立，不会自动同步。
- 本次为 Alpha 测试版；系统选词手柄、软键盘和不同品牌真机交互仍需用户验收。

CI 在发布前执行单元测试、完整浏览器验收、Android lint、签名验证、实际版本号和离线资源检查。附 `SHA256SUMS.txt` 与签名验证报告。
