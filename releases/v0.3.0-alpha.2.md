# 栖读 v0.3.0-alpha.2

阅读器正式命名为「栖读」，更新手机桌面图标和界面印章。

- 新图标为朱砂藏书印：线装书与书房屋檐合形，配暖宣纸底。
- 修复界面文字印章溢出；适配安卓圆形、自适应及 Android 13 主题图标，补齐 iOS、PWA 图标和启动资源。
- 保留内置寻书、下载自动入库、PDF / TXT / EPUB 阅读、进度、书签和笔记。

## 安卓安装

下载下方 `book-reader-v0.3.0-alpha.2.apk`，直接覆盖安装。版本号为 `30002`，沿用「阅读器·古风版」及 `v0.3.0-alpha.1` 的应用 ID 与固定 Alpha 签名，无须卸载原应用。更新后的桌面名称为「栖读」。

更早的独立应用「阅读器」使用不同应用 ID，需先在旧应用导出完整备份，再在栖读中恢复。

构建流水线会检查实际 APK 的名称、版本、固定签名和离线资源；校验文件为 `SHA256SUMS.txt` 与 `SIGNATURE.txt`。这是个人使用的 Alpha 测试版本。
