# 内置寻书试用版

- 新增「寻书」导航、三个书源入口、自定义书源收藏、网址输入和最近访问。
- 原生内置浏览器接管网页下载，并复用现有导入与指纹查重流程。
- 支持 EPUB / PDF / TXT 下载后自动入库、错误提示、入库失败重试和立即阅读。
- 每次下载使用独立缓存目录；成功持久化后才清理原生临时文件。
- 新增 iOS 原生工程与模拟器编译工作流。

这是首个实现版本。网页回执模拟测试不能代替 Android / iPhone 真机验收。下载时保持找书窗口打开；不承诺锁屏后台续传。网页 / PWA 无法通过此次更新直接获得原生下载能力。

构建、已知边界与真机验收清单见 [内置寻书说明](../docs/BOOK_BROWSER.md)。
