# 芸窗 v0.3.0-alpha.3

- 「栖读」更名为「芸窗」，保留朱砂藏书印图标。
- 新增回读窗：从目录、书签、笔记和搜索临时回看，关闭后保持原位置；选「读这里」才跳转。
- TXT / EPUB 竖向滚动到章末后，再次上滑进入下一章。
- 新增远山、竹影两款阅读背景，以及四款古风书封，可在外观与整理藏书中选择。

## 安卓更新

下载 `book-reader-v0.3.0-alpha.3.apk` 覆盖安装「栖读」或「阅读器·古风版」。本版保留原应用 ID 和固定 Alpha 签名，版本号递增为 `30003`。安装完成后桌面名称为「芸窗」。

PDF 保持固定版式，阅读背景显示在页面周围；移动浏览器触摸模拟测试不等同于真机体验。签名与 SHA-256 校验结果随安装包发布。
